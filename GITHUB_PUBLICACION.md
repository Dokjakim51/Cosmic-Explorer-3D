# Guía rápida para publicar Cosmic Explorer

## 1. Crea el repositorio

- **Nombre sugerido:** `Cosmic-Explorer-3D`
- **Descripción:** `Plataforma web interactiva de exploración espacial con Three.js, planetas y estrellas 3D, galería cósmica, asistente Kira y minijuego.`
- **Visibilidad:** Público, después de comprobar los derechos de los archivos multimedia.
- **Temas:** `javascript`, `threejs`, `webgl`, `space`, `astronomy`, `3d`, `interactive-website`, `frontend`.

## 2. Qué archivos debes subir

Sube todos los archivos y carpetas de la raíz de `Cosmic_Explorer_GitHub`, incluidos `.github`, `.gitignore`, `src`, `public`, `scripts`, `tests` y los archivos de créditos. **No subas la carpeta que contiene el ZIP como una carpeta anidada adicional.**

No subas `node_modules`, `dist`, `.env`, archivos personales ni música añadida al reproductor desde tu computadora.

## 3. Comprobar después de subirlo

GitHub debería mostrar automáticamente el `README.md` en la página principal del repositorio. La pestaña **Actions** ejecutará `npm run verify` y debería quedar en verde.

Si quieres una demostración online, conecta GitHub a Netlify. El archivo `netlify.toml` ya configura la compilación (`npm run build`) y salida (`dist`).

## 4. Revisión final de publicación

Consulta [DEPLOYMENT_CHECKLIST.md](DEPLOYMENT_CHECKLIST.md). En particular revisa que los permisos de distribución de cada recurso externo permitan su uso público, que los créditos estén completos y que no queden archivos personales.

## 5. Para tu currículum

**Cosmic Explorer | JavaScript · Three.js · HTML · CSS**

Plataforma de exploración espacial con modelos 3D interactivos, información astronómica, galería de fenómenos, asistente contextual y minijuego integrado.
