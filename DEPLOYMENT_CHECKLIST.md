# Comprobación antes de publicar

- [ ] Revisar créditos, atribuciones y permisos de todas las texturas y archivos multimedia.
- [ ] Ejecutar `npm ci` con Node.js 20 o superior.
- [ ] Ejecutar `npm run verify` sin errores.
- [ ] Abrir `npm run preview` y comprobar Home, Universe, planetas, estrellas y Gallery.
- [ ] Comprobar Kira, favoritos, temas, reproducción de música y Cosmic Defender.
- [ ] Probar navegación móvil y escritorio, accesibilidad de teclado y sonidos.
- [ ] Configurar el repositorio GitHub y conectar Netlify.
- [ ] Confirmar en la URL pública que los recursos no devuelven 404.
- [ ] Tomar capturas para mostrar el resultado en GitHub y el currículum.
