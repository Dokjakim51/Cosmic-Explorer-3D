# Limitaciones y pruebas pendientes

- El código se compiló y verificó localmente; **no se ha verificado una URL de Netlify publicada**.
- La visualización 3D requiere navegador moderno con WebGL; validar en dispositivos físicos.
- Audio sujeto a las restricciones de reproducción automática del navegador.
- Kira utiliza respuestas locales/contextuales, no una API de IA generativa.
- Verificar independientemente licencias y atribuciones de los recursos gráficos y sonoros antes de poner el sitio público.
- La versión rebrandeada usa espacio propio de datos del navegador; las preferencias antiguas no migran automáticamente.
